Q1. Advantages of object oriented programming language.
Object-oriented programming (OOP) offers several advantages:
1. *Modularity*: OOP allows you to break down your software into smaller, manageable modules or objects. This makes it easier to maintain, update, and debug code.
2. *Reusability*: Objects can be reused in different parts of the program or in different programs altogether, saving development time and effort.
3. *Encapsulation*: Objects encapsulate data and behavior together, hiding the internal state and requiring interaction only through well-defined interfaces. This enhances security and reduces system complexity.
4. *Abstraction*: OOP allows you to create abstract data types that model real-world entities. This helps in understanding the code and designing systems more intuitively.
5. *Inheritance*: Inheritance allows new classes to be derived from existing ones, inheriting their properties and behaviors. This promotes code reuse and enables the creation of hierarchical relationships between classes.
6. *Polymorphism*: Polymorphism allows objects of different classes to be treated as objects of a common superclass. This promotes flexibility and simplifies code maintenance by enabling the use of the same interface for different types of objects.

Q4.Write a short note on constraints and variable in c++?
ans: In C++, constraints and variables are fundamental concepts in oops programming. 

1. *Constraints:* Constraints are conditions or limitations applied to variables. They define the range of values or properties that a variable can have. In C++, constraints can be enforced through various means such as conditional statements (if-else), loops, or explicit checks within the code. For example, constraints can restrict a variable to be within a certain range, to meet specific conditions, or to adhere to certain data types.

2. *Variables:* Variables are containers used to store data values in a program. They have a name, a data type, and a value associated with them. In C++, variables must be declared before they can be used, specifying the data type they will hold. Variables can hold different types of data such as integers, floating-point numbers, characters, and user-defined types.

Q13.explain implict and explicit type casting.
ANs:Implicit Type Casting: Implicit type casting, also known as automatic type conversion, occurs when the compiler automatically converts one data type to another without any explicit instructions from the programmer. This usually happens when a narrower data type is assigned to a broader data type. For example:
int a = 10;
double b = a; // Implicit conversion from int to double

In this example, the integer variable a is implicitly converted to a double when assigned to the variable b. This happens because a double can represent a wider range of values compared to an int, so the conversion is safe and automatic.

Explicit Type Casting: Explicit type casting, also known as type casting or type conversion, occurs when the programmer explicitly instructs the compiler to convert one data type to another. This is done using type casting operators. There are different types of explicit type casting operators in C++, such as static_cast, dynamic_cast, reinterpret_cast, and const_cast.

double b = 10.5;
int a = static_cast<int>(b); // Explicit conversion from double to int using static_cast
In this example, the static_cast operator is used to explicitly convert the double variable b to an integer and assign it to the variable a.

13.Explain the rules of making varaibles?
answer:In C++, variables are named memory locations used to store data. Here are the rules for naming variables in C++:
1. Variable names must start with a letter (a-z or A-Z) or an underscore (_).
2. After the first character, variable names can contain letters, digits (0-9), and underscores.
3. C++ is case-sensitive, so uppercase and lowercase letters are distinct. For example, "myVar" and "MyVar" are different variables.
4. Variable names cannot be keywords or reserved words, such as "int", "double", "if", "for", etc.
5. Variable names should be descriptive and meaningful to enhance code readability.
6. There is no limit to the length of variable names, but it's recommended to keep them concise and clear.
7. Avoid using special characters like $, %, &, etc., in variable names, as they are not allowed.

Q2.Concept of Constructor and Destructor.
answer:Constructor:

A constructor is a special member function with the same name as the class, used to initialize objects of that class.
Constructors are automatically called when an object of the class is created.
Constructors can have parameters (parameterized constructors) or no parameters (default constructors).
If no constructor is provided by the programmer, C++ provides a default constructor implicitly.
Constructors can be overloaded, meaning a class can have multiple constructors with different parameters.

Destructor:

A destructor is a special member function with the same name as the class but prefixed with a tilde (~). For example, for class MyClass, the destructor is ~MyClass().
Destructors are automatically called when an object goes out of scope, or delete operator is used to deallocate memory allocated with new.
Destructors are used to release resources (like dynamic memory, file handles, etc.) acquired by the object during its lifetime.
C++ automatically generates a default destructor if one is not provided by the programmer. The default destructor does nothing.
